# 🚂 Indian Railway EDA

Exploratory Data Analysis of a synthetic railway dataset using Python, Pandas, NumPy, and Matplotlib.

> **Note:** This is a synthetic dataset created for educational and portfolio purposes. It is not official Indian Railways data.

## 📌 Project Overview

This project analyzes railway journeys to identify patterns in:

* Passenger demand
* Train and route performance
* Ticket prices and classes
* Delays and cancellations
* Monthly travel trends
* Revenue

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## 🔍 Analysis Performed

* Data cleaning and missing-value analysis
* Duplicate detection
* Feature engineering
* Train and route analysis
* Class-wise passenger and revenue analysis
* Delay and cancellation analysis
* Monthly and weekly trends
* Revenue analysis
* Data visualization
* Business and operational insights

## 📊 Dataset

The dataset contains **10,012 railway journey records** with information about trains, routes, passengers, ticket prices, delays, weather, classes, cancellations, and revenue.
